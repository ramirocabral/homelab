# Ansible

Configures the machines Terraform creates, and the VPS. Run everything from the repo root;
`make deps` installs the collections once.

| Command | Playbook | Inventory | Configures |
| :--- | :--- | :--- | :--- |
| `make site` | `site.yml` | `inventory.ini` | The k3s nodes |
| `make edge` | `edge.yml` | `edge.ini` | The `edge` VM: Nginx Proxy Manager as a Podman quadlet |
| `make vps` | `vps.yml` | `offsite.ini` | The VPS: WireGuard to the MikroTik, Gatus, restic REST server |
| `make backup` | `backup.yml` | `offsite.ini` | The `backup` container on the NAS: nightly restic to the VPS |

`inventory.ini` is generated by Terraform from `k3s_nodes` in `terraform/fleet.auto.tfvars`
(`make inventory`), so don't edit it. `edge.ini` and `offsite.ini` are edited by hand. Secrets
go in `group_vars/*/secrets.yml`, which git ignores.

## k3s

`make site` prepares every node, installs the iGPU drivers where `igpu = true`, sets up the
Longhorn disk on the workers, installs the server, joins the agents and applies the node labels.
It leaves a kubeconfig in `ansible/kubeconfig`:

```bash
export KUBECONFIG=$PWD/ansible/kubeconfig
kubectl get nodes    # NotReady until Cilium is installed
```

The nodes stay `NotReady` because k3s runs without flannel or kube-proxy. Next, install Cilium and
Argo CD by hand from `bootstrap/` in
[homelab-gitops](https://github.com/ramirocabral/homelab-gitops), and Argo CD deploys the rest.

To change a node label, edit `fleet.auto.tfvars` and run `make labels`.

## Decisions

- **Labels with `kubectl label`, not k3s' `--node-label`:** kubelet only reads that flag when the
  node first registers. The role also removes labels under `node_label_domain` that the fleet no
  longer declares.
- **The Longhorn disk is found through `/dev/disk/by-id/`, never `/dev/sdX`:** the SCSI order
  changes between kernels, and attached Longhorn volumes show up as more `sdX` disks. The role
  won't format a disk that has partitions.
- **The `gpu` role checks that the `render` group is gid 991,** because Jellyfin's
  `supplementalGroups` uses that number. If `/dev/dri/renderD128` is missing, the iGPU was never
  attached: see `scripts/igpu-passthrough.sh`.
- **The edge proxy is a VM, not an LXC:** NPM only ships as a container image, and containers
  nested in an LXC have broken with PVE and runc updates before.

## Gotchas

- **k3s flags only apply on the first install.** The install task skips nodes that already have
  k3s. To change a flag, uninstall it (`/usr/local/bin/k3s-*-uninstall.sh`) or edit the config on
  the node and restart the service.
